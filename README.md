# 🎓 Projeto Front-End: Apresentação do Grupo

> Meu primeiro projeto da faculdade: um site institucional feito em grupo para apresentar cada integrante da equipe.

🌐 **Demo:** [matheusamancio06.github.io/projeto-front-end](https://matheusamancio06.github.io/projeto-front-end/)

## ✨ Páginas

- **Início:** apresentação do grupo, com a história e as competências de cada integrante
- **Galeria:** galeria de imagens da equipe
- **Cadastro:** formulário com nome, e-mail, contato e opinião

## 🛠️ Tecnologias

Desenvolvido com **HTML5, CSS3 e JavaScript** puros, com uma folha de estilo e um script para cada página.

## 🚀 Como executar

1. Clone o repositório:

    git clone https://github.com/matheusamancio06/projeto-front-end.git

2. Abra o arquivo index.html no navegador.
